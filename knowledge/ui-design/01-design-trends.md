# 01 - 2025-2026 全球 UI 设计趋势全景

## 一、核心设计哲学转变

### 1.1 从"扁平化"到"深度感"回归

```
2020-2024: Flat Design → Material Design 3 → 
2025-2026: Spatial Design（空间感设计）
```

**特征**：
- 多层阴影叠加（不是单一 box-shadow，而是多光源阴影系统）
- Z 轴层次感：前景、中景、背景通过 blur + opacity 区分
- 微妙的景深效果（depth of field）
- 卡片悬浮感增强

**实现**：
```css
/* 多层阴影 - 现代卡片 */
.card {
  box-shadow:
    0 0 0 1px rgba(0,0,0,0.04),      /* 边框 */
    0 1px 3px rgba(0,0,0,0.06),       /* 近距 */
    0 4px 16px rgba(0,0,0,0.08),      /* 中距 */
    0 8px 32px rgba(0,0,0,0.04);      /* 远距 */
}
```

### 1.2 Glassmorphism 2.0（玻璃态 2.0）

进化版毛玻璃效果，不再是简单的 backdrop-filter。

**关键特征**：
- 半透明背景 + 微妙边框光晕
- 动态模糊随滚动变化（实验性）
- 结合渐变色叠加
- 仅用于重点区域（如导航栏、浮动面板），不过度使用

```css
.glass-panel {
  background: rgba(255, 255, 255, 0.7);
  backdrop-filter: blur(20px) saturate(180%);
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  border: 1px solid rgba(255, 255, 255, 0.5);
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.08);
}
```

### 1.3 Bento Grid（便当盒布局）⭐ 爆款趋势

Apple 推广的卡片网格布局，2025-2026 最热门布局模式。

**特征**：
- 不同尺寸的圆角卡片组成网格
- 每张卡片承载一个独立信息单元
- 大卡片放重点内容，小卡片放辅助信息
- 圆角统一（16-24px），间距一致（12-16px gap）
- 非常适合仪表盘、产品首页、数据展示

```
┌─────────────────────┬──────────┐
│                     │  card B  │
│     card A          ├──────────┤
│    (hero)           │  card C  │
│                     │          │
├──────────┬──────────┴──────────┤
│ card D   │      card E         │
├──────────┤                    │
│ card F   │                    │
└──────────┴────────────────────┘
```

参考产品：Apple 官网、iOS 设置、Linear、Notion Calendar

### 1.4 超大字体 + 极简留白

- Hero 区域字号 48-96px
- 使用可变字体（Variable Fonts）
- 大量留白让内容"呼吸"
- 减少装饰元素，让字体本身成为视觉焦点

### 1.5 AI 原生界面（AI-Native UI）

- 对话式交互成为主导导航
- 传统菜单退居二线
- 流式内容渲染（streaming UI）
- 渐进式信息披露

## 三、反模式（2025 年应避免的过时设计）

| 过时模式 | 替代方案 |
|----------|----------|
| 纯扁平化无阴影 | 空间层次感阴影 |
| 过度的 Neumorphism | 克制的 Glassmorphism |
| 12px 以下正文字号 | 最小 14px（移动端 15px） |
| 高饱和渐变背景 | 流体柔和渐变或网格纹理 |
| 传统侧边栏 + 顶部导航 | 底部标签栏（移动端）/ 命令面板（桌面端） |
| 弹出模态框 | 底部抽屉 / 行内展开 |
| 长表单 | 分步向导 / 对话式输入 |
