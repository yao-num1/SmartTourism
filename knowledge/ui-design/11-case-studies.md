# 11 - 爆款产品 UI 拆解案例

## 一、携程旅行 App

| 维度 | 分析 |
|------|------|
| 首页布局 | 搜索栏 Sticky + Bento Grid 功能卡片 |
| 配色 | 蓝(#0086F6)白为主，橙色(#FA9E0D)点缀 CTA |
| 字体 | PingFang SC, 标题 18px+, 正文 14px |
| 动效 | 卡片按压缩放，价格数字跳动动画 |
| 可借鉴 | 行程规划 Bento Grid 布局、酒店卡片样式 |

## 二、小红书

| 维度 | 分析 |
|------|------|
| 内容布局 | 双列瀑布流 (columns: 2) |
| 图文比例 | 3:4 竖图主导，适配手机全屏 |
| 标签系统 | 话题标签可点击跳转 |
| 动效 | 点赞爱心粒子爆炸、收藏星星闪烁 |
| 可借鉴 | UGC 图文混排、标签导航 |

## 三、Airbnb

| 维度 | 分析 |
|------|------|
| 搜索交互 | 分类横向滑动 Chips（图标+文字） |
| 详情页 | Sticky 底部预订栏 + 全屏图片轮播 |
| 卡片设计 | 圆角 16px，阴影极浅，图片占比 70% |
| 可借鉴 | 住宿推荐卡片、分类筛选 Chips |

## 四、ChatGPT

| 维度 | 分析 |
|------|------|
| 对话设计 | 极简白底 + 圆角气泡 + 流式打字 |
| 侧边栏 | 历史对话列表，支持重命名/删除 |
| 输入区 | 底部固定，多行自适应 |
| 消息交互 | 复制/重新生成/点赞踩/语音朗读 |
| 可借鉴 | 流式渲染、消息操作菜单 |

## 五、Linear

| 维度 | 分析 |
|------|------|
| 暗色模式 | 极致暗色 (#0D0D12)，精心设计的灰色层次 |
| 命令面板 | Cmd+K 全局搜索/导航 |
| 加载状态 | 乐观更新 + Skeleton Placeholder |
| 微交互 | Issue hover 出现操作按钮，拖拽排序 |
| 可借鉴 | 暗色主题色彩体系、键盘快捷键设计 |

## 六、Stripe

| 维度 | 分析 |
|------|------|
| 渐变背景 | 软件感流体渐变（蓝紫+粉） |
| 按钮 | 光泽质感 Hover，渐变边框 |
| 排版 | 超大 Display 字体 Hero + 充分留白 |
| 动效 | 滚动触发的视差效果 |
| 可借鉴 | 品牌质感、Hero 区域设计 |

## 七、Apple 官网
