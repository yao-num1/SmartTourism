# 智旅灵犀 · SmartTourism v2.2

> 文旅全场景智能辅助系统 —— 游客画像驱动 + 消费转化设计 + 文创产品赋能

## 📖 项目简介

智旅灵犀是一个面向文旅行业的场景智能辅助系统，针对景区、酒店、餐饮、文创核心业态中**消费体验同质化、客源转化效率低、产品创新迭代慢**三大痛点，基于 Flask + 国产大模型 API + 高德地图构建，通过轻量化智能 Skill 协同工作，实现文旅智能咨询、画像驱动行程规划、营销创收内容生成、文创产品赋能、客源精准匹配五大核心场景的智能化。系统强调“因人而异、因场景而异、因经营目标而异”，把传统行程和文案生成升级为“游客满意 + 商家创收”的闭环。

### 目标用户

| 用户类型 | 典型角色 | 核心价值 |
|----------|----------|----------|
| 文旅从业者 | 景区运营、酒店营销、文创开发 | 快速生成营销素材、优化行程推荐、提升客源转化 |
| 高校学生 | 旅游管理、数字媒体、文化创意 | 动手实践 AI Agent 开发与创新项目 |
| 文旅研究者 | 行业分析师、高校教师 | 开放架构支持模型替换、数据导入、策略对比 |

## 🎯 核心功能

| 模块 | 功能 | 技术实现 |
|------|------|----------|
| 💬 智能对话 | AI 驱动的文旅问答 | 4 大国产模型热切换 + 流式输出（可中途**停止生成**，半截答复按「未完整」如实落库）+ 知识库检索**出处可见**（每轮可展开「参考来源」，没命中不做假标注）+ **多会话管理**（历史对话可切换 / 改名 / 删除，新建对话不删旧内容）+ **重新生成 / 编辑重发**（只撤回这一轮，对不上就不删）+ **答复点赞 / 点踩落库**（一票一答复，改票覆盖，没落库不给按钮）+ 输入框轮换提示词 + 每轮回答后给出可点击的「你可以继续问」追问 chips |
| 🗺️ 场景智能行程 | 个性化游玩旅居餐饮方案 | 参数校验 + 结构化骨架预处理 + 数据来源标注 + 异常兜底 + 保存/修改/导出（地图已去掉顶部出行方式状态栏，出行方式由左侧表单驱动） |
| ✍️ 营销创收 | 多平台内容与转化方案生成 | 小红书/公众号/OTA差异化 + 主推产品 + 转化路径 + 合规检查；生成结果**完整显示在单一内容框**（不再拆成断章），支持一键复制与**转化为数字名片** |
| 🔥 灵感库（实时热点） | 每次更新换入 10 张主题灵感卡 | 按 国潮/非遗/博物馆/文创IP/节庆 检索实时热点 → **文创可用性二次验证** → 分类均衡出卡；滚动热点池保证连续更新不重复，卡片带真实热度值 |

| 🔖 文创数字名片 | 实物印码即媒介：扫码前看噱头、扫码后看详情 | 灵感产品/海报/营销内容多入口一键生成短链+二维码；**应用内只展示吸引内容（核心定位/一句话传播语 + 亮点）与二维码**，扫码打开的 H5 名片才展示大图 · 亮点速览 · 深入了解 · 文化背景 · 设计理念与购买跳转，码印包装上即成传播节点 |

| 🎯 客群匹配 | 客群画像 + 精准匹配 | 6 组客群画像 + 多人满意度平衡 + 产品/消费触点匹配 |

| 🔌 数据插件 | 实时数据注入 | 天气/高德POI/本地知识库/飞猪接口 |
| 🗺️ 地图导航 | GPS定位 + 周边搜索 | 高德地图 Web API + JS API 2.0；地图加载失败时给出可读原因 + 「重新加载地图」/「高德网页版查看」降级出口，网络恢复自动重试 |

## 🔧 近期完善（针对竞赛主办方关注点）

### 规划功能
- **参数完整性校验**：缺少目的地/天数/同行关系时，优先返回澄清话术，不直接假设生成。
- **结构化骨架预处理**：`plan_generator.py` 接入 `/api/plan`，先由规则生成每日主题、消费点、预算框架，再由 LLM 润色，体现 AI + 规则的混合优势。
- **数据来源声明**：所有价格/开放时间必须标注来源（本地知识库、高德 POI、AI 推断）。
- **异常兜底**：LLM 失败、插件异常时返回最小可用行程框架，并提示用户二次确认。

### 对话上下文管理（防幻觉 + 长对话控制）
- **Token 预算 + 滑动窗口**（`server/context_manager.py`）：按预算组装历史消息——system 与当前问题永不删，最近 4 轮完整保留，更旧的轮次在预算内从最新往前装，装不下的不再硬塞（替代旧的「固定取最近 20 条」硬截断）。
- **滚动摘要**：被预算丢弃的早期轮次由 LLM 压缩成 ≤150 字摘要（增量折叠、不重复压缩），作为「对话早期摘要」放在消息列表前部；摘要生成失败自动降级为直接丢弃，不影响对话。压缩发生时前端轻提示「已自动压缩早期内容」。
- **事实锚定防漂移**：每轮把会话已确认信息（目的地/天数/预算/人群）重新注入当前消息开头，防止长对话中模型偏离用户已确认约束。
- **防幻觉组合拳**：按 Skill 动态温度（咨询低/营销高）+ 用户纠正信号检测 + 会话事实追踪 + RAG 知识库检索 + 回复后校验（validation 事件标注待核实内容）。
- 预算/保留轮数/触发线可用环境变量调整：`CTX_BUDGET`（默认 24000）、`CTX_RECENT_ROUNDS`（默认 4）、`CTX_COMPRESS_TRIGGER`（默认 0.75）。
- **占用可视化 + 到线自动压缩**：每轮通过 SSE 下发 `type: context`（占用比例、触发线、装入轮数、折叠轮数、压缩档位），对话页顶部进度条实时显示；占用达到「预算 × 触发线」即折叠旧轮次，不等撑满——预留 25% 给插件实时数据/RAG 的单轮尖峰。前端按 60%/85% 变色并 clamp 到 100%，真实百分比写在数字与悬浮详情里。

### 文创功能
- **独立文创 Prompt**：`/api/creative` 不再复用营销文案 Prompt，使用专门的“文化元素提取 → IP 合规检查 → 产品梯度 → 包装故事 → 联动销售 → 海报提示词”流程。
- **IP 合规检查**：自动评估文物/遗址、宗教/民族、名人/非遗、商标/品牌、地图/国旗等风险。
- **海报联动**：文创方案输出后，可一键调用火山方舟 Seedream 生成形象款概念海报，并在前端展示。
- **文创数字名片（实物印码即媒介）**：灵感页产品卡片与营销页海报结果均支持一键生成数字名片——后端 `/api/cards` 存储产品图文，前端生成专属 H5 短链 + 二维码，手机打开即看文化故事/设计理念/购买跳转。商家把二维码印在包装或展架上，实物本身成为传播节点，区别于市面上"只能生成文案"的同质化工具。
- **灵感库数据可考究**：卡片来源分层标注——抖音检索到的真实热点标「热点灵感」并展示真实热度值，本地行业趋势观察标「趋势观察」。所有卡片不显示价格，「非实物 · 仅供参考」统一放在收藏按钮下方；简介只讲热点能带来什么灵感，不再混入免责声明，杜绝把合成价格/销量包装成电商数据。
- **灵感库配图统一 AI 生图**：所有灵感卡的配图由火山方舟 Seedream 按"产品名 + 主题 + 城市"现场生成概念图（`GET /api/inspire/image` 懒生成 + 磁盘缓存 + 12 路并发），前端先显示流光占位再自动替换，不再出现卡通示意图占位；生成失败回退产品本地图或主题配色图。
- **核心内容模式（灵感 → 数字名片直通）**：从灵感库「提取灵感填充营销」后再生成，后端走 `core_only` 分支，只产出 ≤700 字的 5 个核心模块，避免长篇方案挤爆名片；保存后可直接「用核心内容生成数字名片」，名片页把这段内容自动拆成「深入了解」分段供扫码者继续阅读。
- **抓取 + 二次验证双保险**：检索词池只保留实测有效的近义词，按刷新种子轮换关键词与页码；抓到的每条热点必须通过文创可用性校验（命中国潮/非遗/博物馆/文创IP/节庆主题词 + 文创营销信号，剔除新闻/负面/无关热搜）才进入卡片，分类按内容重新判定；通过的内容进入 12 小时滚动热点池并落盘，每次更新优先放出未展示过的条目，从根本上解决"第二次更新没有新内容"。

## 🚀 快速开始

### 环境要求
- Python 3.8+
- Windows / macOS / Linux

### 安装与启动

```powershell
# 1. 进入项目目录
cd D:\SmartTourism

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动服务
python server\app.py
# 或双击 start.bat（Windows）
```

### 首次使用
1. 浏览器打开 `http://localhost:5050`
2. （可选）点击右上角「👤 登录」注册/登录账号（账号 + 密码 + 图片验证码）；不登录则以游客身份使用，登录后数据按用户独立保存
3. 点击右上角 ⚙️ 进入设置，**只需选择要使用的模型**（API Key 由运维在后台统一配置，前端不再采集）
4. 开始对话体验

### API Key 配置（后台）

> 出于简化前台操作的考虑，模型/图片/地图等 API Key 一律在**后台**配置，前端设置页只保留「模型切换」。

| 用途 | 配置位置 |
|------|----------|
| 大模型（DeepSeek/智谱/通义/Kimi） | `server/app.py` 的 `API_CONFIG`（或运行期 `POST /api/config` 仅切换 provider） |
| 火山方舟图片（文创海报/灵感配图） | `data/ark_config.json` 的 `api_key`（`doubao-seedream-4-5-251128` 文生图，`POST https://ark.cn-beijing.volces.com/api/v3/images/generations`） |
| 火山方舟图片（旅游博客配图，可独立） | 同上文件的 `blog_api_key` / `blog_model` / `blog_size`。填了就只服务博客主视觉图文海报·场景图·美食图，留空则回落到 `api_key` / `model`；主视觉自动渲染【海报标题+推广语】成图文并茂的推广海报（当前模型 `doubao-seedream-5-0-pro-260628`） |
| 高德地图 / 美团 / 飞猪等插件 | `data/plugin_config.json` |

当前生效的图片接口配置可随时用 `GET /api/ark/config` 查（返回 endpoint / model / size / watermark，不含明文 Key）。

各供应商注册地址：DeepSeek https://platform.deepseek.com · 智谱 GLM https://open.bigmodel.cn · 通义千问 https://dashscope.aliyun.com · Kimi https://platform.moonshot.cn

### 配置高德地图（可选）

1. 注册 [高德开放平台](https://lbs.amap.com)
2. 创建应用 → 添加 Web 服务 API Key
3. 把 Key 填入后台 `data/plugin_config.json`（`amap_key` / `amap_js_key`）

## 🔌 插件系统

```
用户输入 → 意图识别 → 自动触发插件 → 数据注入 → LLM 回答
                │
                ├── 🌤️ weather     → 实时天气
                ├── 📚 knowledge    → 酒店/景点/美食/交通
                ├── 🗺️ amap_poi    → 周边 POI 搜索
                └── 🐷 fliggy      → 飞猪套餐（预留）
```

### 扩展新插件只需 3 步：

1. 创建 `plugins/myplugin.py`，继承 `BasePlugin`
2. 定义 `trigger_keywords`（触发词）和 `execute()`（数据获取逻辑）
3. 在 `app.py` 中 `registry.register(MyPlugin())`

## 💡 创新点

1. **轻量级零框架 SaaS** — 前后端零框架依赖，5 秒启动

## 🔒 安全

- API Key 统一在**后台**配置（`server/app.py` 与 `data/*.json`），前端设置页不再采集密钥
- 登录口令使用 PBKDF2-HMAC-SHA256（10 万次迭代 + 随机盐）散列存储，登录/注册需图片验证码（一次性、5 分钟有效）
- 会话采用 Bearer Token（有效期 7 天），用户数据按 `user_id` 隔离
- 插件数据缓存 10-30 分钟
- 对话/订单等内容持久化到 SQLite + 按用户命名空间的 localStorage（产品未上线，数据仅存本机），支持导出和清空
- 除账号登录所需外，不额外收集用户个人信息
