0总体架构与目标

抖音小程序要求后端接口必须通过 https:// 访问，且域名必须完成 ICP 备案。本方案将现有 Flask 后端从 http://localhost:5000 迁移到公网 HTTPS，整体架构如下：

┌─────────────────────────────────────────────────────────┐ │ 抖音 App / 抖音 Lite │ │ 小程序前端 (douyin-miniapp/) │ └────────────────────────┬────────────────────────────────────┘ │ HTTPS 请求 ▼ ┌─────────────────────────────────────────────────────────┐ │ 公网域名 (已备案 + SSL 证书) │ │ https://api.lingxiwenlv.icu │ └────────────────────────┬────────────────────────────────────┘ │ ▼ ┌─────────────────────────────────────────────────────────┐ │ Nginx (反向代理 :443) │ │ SSL 终止 · 静态文件 · 请求转发 │ └────────────────────────┬────────────────────────────────────┘ │ HTTP (内网 127.0.0.1:5000) ▼ ┌─────────────────────────────────────────────────────────┐ │ Gunicorn (WSGI 服务器 · 4 workers) │ │ 运行 server/app.py Flask 应用 │ ├─────────────────────────────────────────────────────────┤ │ Flask API: /api/chat · /api/plan · /api/marketing │ │ /api/social/hotspots · /api/map/* │ ├─────────────────────────────────────────────────────────┤ │ 插件系统: 天气 · 高德POI · 本地知识库 │ │ 数据存储: SQLite (data/smarttourism.db) │ └─────────────────────────────────────────────────────────┘
核心目标 将 python server/app.py 开发模式升级为 Gunicorn + Nginx 生产模式，通过 HTTPS 对外提供服务，满足抖音小程序安全域名要求。

3第二步：域名注册与 ICP 备案

3.1 域名注册

在阿里云/腾讯云域名控制台注册域名。推荐 .com 或 .cn，年费约 35-79 元。域名后缀必须被工信部收录才能备案 [$TRAE_REF](https://cloud.tencent.com/document/product/243/55796)。

3.2 ICP 备案流程

ICP 备案是使用国内服务器的强制要求，也是抖音小程序安全域名配置的前提。备案大约需要 7-20 个工作日 [$TRAE_REF](https://m.sohu.com/a/974712415_100234582/)。

注册云账号并实名认证

个人备案需身份证 + 人脸核验；企业备案需营业执照 + 法人证件。

购买云服务器

服务器需在中国大陆地域，且购买时长 ≥ 3 个月。

注册域名

域名需完成实名认证（1-3 个工作日）。

提交备案申请

通过云服务商备案系统提交，填写主办单位信息、上传证件、完成人脸核验。

等待审核

云商初审（1-3 天）→ 工信部审核（5-20 天）→ 备案通过，获得备案号。

加速建议 备案期间可以先开发调试小程序。在抖音开发者工具中勾选「不校验合法域名」，即可用 http://localhost:5000 本地开发。备案通过后再切换到正式 HTTPS 域名。

6第五步：项目部署（Gunicorn + Nginx）

5.1 Gunicorn 启动配置

Gunicorn 是 Python WSGI HTTP 服务器，用于替代开发模式的 app.run(debug=True)，支持多 worker 进程并发处理 [$TRAE_REF](https://www.cnblogs.com/ppzhang/p/14421472.html)。

# 手动测试启动（确认无报错）
cd /opt/smarttourism
source venv/bin/activate
gunicorn -w 4 -b 127.0.0.1:5000 "server.app:app" --timeout 120

# 参数说明：
# -w 4         4 个 worker 进程（建议 CPU 核数 × 2）
# -b           绑定内网地址，不直接暴露公网
# --timeout    请求超时 120 秒（AI 接口响应较慢）
# "server.app:app"  指向 server/app.py 文件中的 app 对象

5.2 systemd 服务配置（开机自启）

# 创建 systemd 服务文件
sudo nano /etc/systemd/system/smarttourism.service
# /etc/systemd/system/smarttourism.service
[Unit]
Description=SmartTourism Flask API Server
After=network.target

[Service]
User=root
WorkingDirectory=/opt/smarttourism
Environment="PATH=/opt/smarttourism/venv/bin"
ExecStart=/opt/smarttourism/venv/bin/gunicorn -w 4 -b 127.0.0.1:5000 "server.app:app" --timeout 120
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
# 启动并设置开机自启
sudo systemctl daemon-reload
sudo systemctl start smarttourism
sudo systemctl enable smarttourism
sudo systemctl status smarttourism  # 确认状态为 active (running)

5.3 Nginx 反向代理配置

# 创建 Nginx 配置文件
sudo nano /etc/nginx/sites-available/smarttourism
# /etc/nginx/sites-available/smarttourism
server {
    listen 80;
    server_name api.lingxiwenlv.icu;

    # 静态文件（前端页面）
    location /static/ {
        alias /opt/smarttourism/dashboard/;
        expires 30d;
    }

    # API 反向代理到 Gunicorn
    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE 流式响应支持（AI 对话用）
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 180s;
    }
}
# 启用配置并重启 Nginx
sudo ln -s /etc/nginx/sites-available/smarttourism /etc/nginx/sites-enabled/
sudo nginx -t          # 检查配置语法
sudo systemctl restart nginx
验证 HTTP 阶段 此时通过 http://api.lingxiwenlv.icu/api/health 应该能返回 JSON 健康检查结果。如果正常，说明 Gunicorn + Nginx 反向代理已通。

7第六步：HTTPS 配置

方案 A：Let's Encrypt 自动配置（推荐）

# 安装 certbot
sudo apt install -y certbot python3-certbot-nginx

# 自动申请证书并配置 Nginx HTTPS
sudo certbot --nginx -d api.lingxiwenlv.icu

# certbot 会自动：
# 1. 验证域名所有权
# 2. 下载 SSL 证书
# 3. 修改 Nginx 配置（添加 443 端口监听）
# 4. 设置 HTTP 自动跳转 HTTPS

# 测试自动续期（证书 90 天过期，certbot 会自动续）
sudo certbot renew --dry-run

方案 B：阿里云/腾讯云免费 DV 证书

在云控制台申请证书

进入 SSL 证书控制台 → 申请免费 DV 证书 → 填写域名 → DNS 验证。

下载 Nginx 格式证书

下载 .pem（证书）和 .key（私钥）文件。

上传到服务器

放到 /etc/nginx/ssl/ 目录。

修改 Nginx 配置

见下方完整 HTTPS 配置。

完整 HTTPS Nginx 配置

# /etc/nginx/sites-available/smarttourism （最终版）
server {
    listen 80;
    server_name api.lingxiwenlv.icu;
    return 301 https://$host$request_uri;  # HTTP 强制跳转 HTTPS
}

server {
    listen 443 ssl http2;
    server_name api.lingxiwenlv.icu;

    # SSL 证书路径（Let's Encrypt 或云厂商下载的证书）
    ssl_certificate     /etc/letsencrypt/live/api.lingxiwenlv.icu/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.lingxiwenlv.icu/privkey.pem;

    # SSL 安全配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256;
    ssl_prefer_server_ciphers off;
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 1d;

    # 静态文件
    location /static/ {
        alias /opt/smarttourism/dashboard/;
        expires 30d;
    }

    # API 反向代理
    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 180s;
    }
}
# 重启 Nginx 使 HTTPS 生效
sudo nginx -t
sudo systemctl restart nginx
验证 HTTPS 浏览器访问 https://api.lingxiwenlv.icu/api/health，确认返回 JSON 且地址栏显示安全锁标志。也可用 curl -I https://api.lingxiwenlv.icu/api/health 检查 HTTP 状态码。

8第七步：抖音小程序安全域名配置

HTTPS 后端就绪后，需要在抖音开放平台配置安全域名，否则小程序正式环境无法发起网络请求 [$TRAE_REF](https://www.kancloud.cn/shangyu/duoxcx/1469925)。

登录抖音开放平台

进入 developer.open-douyin.com → 选择你的小程序 ttb5fec3432b845b4d01。

进入开发设置

左侧导航：开发 → 开发设置 → 服务器域名。

添加 request 合法域名

在「request 合法域名」中添加：https://api.lingxiwenlv.icu

保存并等待生效

保存后通常即时生效，少数情况下需等待几分钟。

更新小程序端配置

修改 douyin-miniapp/utils/config.js，把占位地址替换为正式域名：

// douyin-miniapp/utils/config.js
module.exports = {
  API_BASE_URL: "https://api.lingxiwenlv.icu",
  DEFAULT_CITY: "杭州",
};
安全域名规则 合法域名只支持 https:// 协议，不支持 IP 地址，不支持 localhost。每月最多修改 50 次域名配置 [$TRAE_REF](https://www.cnblogs.com/cntt/articles/12988539.html)。

9运维与安全加固

9.1 环境变量管理（敏感信息）

不要在代码中硬编码 API Key。用环境变量或 .env 文件管理：

# 在服务器上创建环境变量文件
nano /opt/smarttourism/.env
# /opt/smarttourism/.env
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxx
ZHIPU_API_KEY=xxxxxxxxxxxxxxxx
QWEN_API_KEY=sk-xxxxxxxxxxxx
AMAP_KEY=your-amap-key-here

# 社交平台热点接口（可选）
DOUYIN_HOTSPOT_ENDPOINT=
DOUYIN_ACCESS_TOKEN=
XHS_HOTSPOT_ENDPOINT=
XHS_ACCESS_TOKEN=

在 systemd 服务文件中加载环境变量：

# 在 smarttourism.service 的 [Service] 段添加
EnvironmentFile=/opt/smarttourism/.env

9.2 防火墙配置

# 只开放必要端口
ufw allow 22/tcp
ufw allow 80/tcp
ufw allow 443/tcp
ufw enable
ufw status verbose

9.3 常用运维命令

# 查看应用日志
sudo journalctl -u smarttourism -f

sudo systemctl restart smarttourism
