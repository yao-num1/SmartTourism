# 客源精准匹配 Skill (Smart Matching)

基于 OpenClaw 引擎的文旅客源精准匹配与转化策略引擎，通过客群画像+需求分析+匹配推荐三级流水线，实现"客源需求→产品匹配→转化策略"的智能化闭环。

## 核心能力

| 能力模块 | 功能描述 | 触发场景 |
|---------|---------|---------|
| 客群画像分析 | 多维度客群特征提取与标签化 | "分析一下我的客群画像"、"来我店的游客有什么特点" |
| 需求精准匹配 | 客群偏好→产品/服务智能匹配 | "亲子家庭适合推荐什么房型"、"给商务客群匹配什么餐饮" |
| 转化策略推荐 | 基于客群特征的获客转化方案 | "如何提高情侣客群的转化率"、"设计针对银发族的营销策略" |
| 产品定位优化 | 数据驱动的产品迭代与差异化定位 | "怎样打造差异化产品"、"根据客群反馈调整定位" |
| 个性化消费场景匹配 | 将客群性格、同行关系、预算与门票/餐饮/住宿/文创消费点匹配 | "情侣路线怎么安排更容易消费" |
| 多人满意度平衡 | 识别多人偏好冲突并生成共同满意路线 | "男生喜欢历史，女生喜欢拍照，怎么都满意" |

## 工作流程

### Step 1: 客群画像构建

从用户描述或历史数据中提取客群特征：

**客群画像维度表：**

| 维度 | 字段 | 示例值 |
|------|------|--------|
| 基本信息 | 年龄层、性别、来源地 | 25-35岁/女性为主/一线城市 |
| 消费能力 | 预算区间、消费频次 | 人均500-1000/季均1-2次 |
| 出行特征 | 出行方式、同行人数、天数 | 自驾/2人/2-3天 |
| 偏好标签 | 兴趣、风格、关注点 | 拍照打卡/网红店/性价比 |
| 决策路径 | 信息渠道、预订方式、决策周期 | 小红书种草→OTA预订/提前1周 |
| 痛点需求 | 核心痛点、期望、顾虑 | 排队时间长/想要出片效果好 |
| 性格倾向 | 慢游/探索/拍照/文化/品质/省钱 | 松弛慢游+纪念消费 |
| 同行关系 | 情侣/亲子/朋友/银发/商务/团建 | 情侣二人行 |
| 消费触点 | 愿意付费的项目 | 夜游、摄影、文创、特色餐饮 |

### Step 2: 客群分类匹配

基于文旅行业标准客群分类体系：

```
客群分类体系
├── 亲子家庭（25-40岁，带娃出行）
│   ├── 幼龄亲子（0-6岁）：安全、便利、亲子设施
│   └── 学龄亲子（7-15岁）：寓教于乐、互动体验
├── Z世代（18-28岁，年轻潮流）
│   ├── 学生党：性价比、公共交通、小众打卡
│   └── 职场新人：周末游、氛围感、社交分享
├── 情侣蜜月（22-35岁，浪漫二人行）
│   ├── 热恋情侣：网红打卡、仪式感、私密
│   └── 蜜月旅行：高端舒适、回忆价值、定制
├── 银发康养（55岁以上，慢生活）
│   ├── 活力银发：康养度假、文化体验
│   └── 关怀银发：无障碍、医疗配套、慢节奏
├── 商务出行（30-50岁，效率优先）
│   ├── 商务会议：会议配套、交通便利
│   └── 差旅住宿：效率入住、商务简餐
└── 团建聚会（企业/社团，社交体验）
    ├── 公司团建：拓展项目、团队协作
    └── 朋友聚会：社交空间、娱乐设施
```

### Step 3: 产品匹配引擎

根据客群画像，自动匹配最优产品组合：

```python
# 匹配策略示例
match_strategy = {
    "客群": "亲子家庭·幼龄亲子",
    "产品匹配": {
        "景区": {
            "优先": ["主题乐园", "动物园", "海洋馆"],
            "可选": ["自然景区(平缓)", "科技馆"],
            "避免": ["高危户外", "长途徒步"]
        },
        "酒店": {
            "优先": ["亲子房型", "儿童乐园", "加床服务"],
            "必要设施": ["婴儿床", "儿童餐具", "恒温泳池"],
            "加分项": ["托管服务", "亲子活动", "儿童礼包"]
        },
        "餐饮": {
            "优先": ["亲子餐厅", "自助餐", "包间"],
            "推荐菜品": ["清淡口味", "儿童营养餐", "趣味造型"],
            "避免": ["重口味", "生冷食物", "排队长餐厅"]
        }
    },
    "营销触点": {
        "渠道": ["小红书", "抖音亲子", "妈妈群"],
        "内容方向": ["遛娃攻略", "亲子vlog", "酒店测评"],
        "转化钩子": ["亲子套餐", "早鸟优惠", "儿童免票"]
    }
}
```

### Step 4: 转化策略生成

为匹配结果制定可落地的转化策略：

1. **渠道策略**: 匹配客群活跃的传播渠道
2. **内容策略**: 针对客群偏好的内容类型
3. **产品策略**: 适配客群需求的产品组合设计
4. **定价策略**: 客群可接受的定价区间与促销方式
5. **触达时机**: 客群决策周期内的最佳触达时间点
6. **体验转化策略**: 在行程动线中自然嵌入消费点，避免硬广式推荐

### Step 5: 多人偏好平衡

多人同行时，匹配引擎必须输出：

| 项目 | 要求 |
|------|------|
| 个体偏好 | 分别提取每个成员的兴趣、性格、消费顾虑 |
| 共同满意点 | 找到双方都能接受或共同期待的体验 |
| 轮换满足点 | 按时间段分别满足不同成员需求 |
| 消费联动点 | 推荐能同时满足体验和创收的消费项目 |
| 冲突替代方案 | 当预算、体力、兴趣冲突时给出备选 |

## 客群匹配速查表

| 客群 | 核心需求 | 决策因子 | 传播渠道 | 转化策略 |
|------|---------|---------|---------|---------|
| 亲子家庭 | 安全+便利+亲子设施 | 儿童政策>安全性>娱乐性 | 小红书/抖音/妈妈群 | 亲子套餐、儿童免票 |
| Z世代 | 出片+氛围+性价比 | 视觉效果>价格>体验 | 抖音/B站/小红书 | 打卡种草、社交裂变 |
| 情侣 | 浪漫+私密+仪式感 | 氛围>隐私>景观 | 小红书/抖音/朋友圈 | 套餐预售、节日限定 |
| 银发族 | 康养+文化+慢节奏 | 舒适>健康>文化 | 微信/头条/社区 | 康养套餐、口碑推荐 |
| 商务 | 效率+品质+便利 | 位置>效率>配套 | 携程商旅/飞猪 | 企业协议、会员体系 |
| 团建 | 场地+项目+社交 | 容纳量>项目>餐饮 | 企业HR社群 | 团建套餐、定制方案 |

## 数据分析脚本

### 客群画像生成

```python
# 用 Python 脚本生成客群画像 JSON
python scripts/matching_engine.py --action profile --input user_data.json
```

### 产品匹配推荐

```python
# 基于客群标签匹配最优产品组合
python scripts/matching_engine.py --action match --crowd "亲子家庭" --destination "杭州"
```

### 转化策略生成

```python
# 生成定向转化策略
python scripts/matching_engine.py --action strategy --crowd "Z世代" --channel "抖音"
```
