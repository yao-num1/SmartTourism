# 文创案例集

## 文创产品设计方法论

### 在地文化元素提取框架
1. **自然符号**: 特色地貌、代表性动植物、气象景观
2. **建筑符号**: 标志性建筑轮廓、装饰纹样、斗拱/飞檐
3. **色彩符号**: 在地传统色彩体系（如敦煌色、青花蓝）
4. **文字符号**: 地名书体、传统纹样、民间文字
5. **生活符号**: 饮食器具、民间工艺、服饰纹样

### 文创产品开发梯度

**引流款（¥10-50）**
- 冰箱贴、钥匙扣、明信片
- 设计要点：图案有辨识度、可系列化收集
- 目标：游客"必买"纪念、社交分享触发二次传播

**利润款（¥50-200）**
- 帆布包、笔记本、书签、马克杯、手机壳
- 设计要点：实用+美观、日常使用频率高
- 目标：品牌持续曝光、使用场景广泛

**形象款（¥200-1000）**
- 丝巾、香氛、茶具、文创礼盒
- 设计要点：工艺精致、具有收藏/送礼价值
- 目标：提升品牌调性、高端礼品市场

### 文创产品创意生成器

当用户提供景区/目的地信息后，按以下框架生成创意：

```
景区名称：[XX]
核心文化符号：
  - 自然：[提取1-2个]
  - 建筑：[提取1-2个]
  - 色彩：[提取1-2个]
  - 故事：[提取1个核心IP/传说]

推荐文创产品线：

1. 引流款（¥XX-XX）
   产品：...
   设计概念：...
   文化来源：...

2. 利润款（¥XX-XX）
   产品：...
   设计概念：...
   文化来源：...

3. 形象款（¥XX-XX）
   产品：...
   设计概念：...
   文化来源：...

传播点设计：
  - 小红书种草角度：...
  - 抖音展示角度：...
  - 包装故事线：...
```

## 优秀文创案例参考

### 博物馆文创
- 故宫博物院：从"朕知道了"胶带到数字沉浸展，核心策略是"让文物活起来"
- 敦煌研究院：以壁画元素为核心的丝巾、日历、数字藏品
- 苏州博物馆：以建筑为灵感的茶具、文具系列

### 景区文创
- 迪士尼：IP衍生品全品类覆盖，核心是"每个项目出口都是商店"
- 日本熊本县：熊本熊IP从县域吉祥物到全球知名
- 乌镇：蓝印花布、三白酒等在地非遗的现代化演绎

### 餐饮文创
- 文和友：场景化消费+周边商品
- 茶颜悦色：中式视觉体系+周边杯具
- 星巴克城市杯：收集属性驱动复购
