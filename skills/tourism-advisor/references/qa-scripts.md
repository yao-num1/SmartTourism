# 咨询话术库

## 景区咨询标准话术

### 通用咨询
- "请问XX景区的开放时间是什么？" → 回复包含：旺季/淡季时间、最晚入园时间、节假日特殊安排
- "门票多少钱？" → 回复包含：成人/儿童/老人/学生票价、免票政策、套票/联票、线上购票渠道
- "怎么去XX景区？" → 回复包含：自驾路线+停车场、公共交通线路、景区直通车、打车参考价
- "XX景区适合带小孩/老人吗？" → 回复包含：亲子/适老设施、游玩难度、建议时长

### 深度推荐
- 当用户问"有什么好玩的"时，先确认偏好再推荐
- 推荐景点时附带推荐游玩顺序和时长
- 根据当前季节推荐应季特色

## 酒店咨询标准话术

### 入住咨询
- 当用户提供预算和位置时，推荐至少3家，覆盖不同档次
- 主动询问：入住人数、是否需要加床、是否携带宠物
- 提示：热门时段建议提前X天预订

### 设施咨询
- 回复时区分"免费"与"收费"设施
- 停车场费用单独说明

## 餐饮咨询标准话术

### 推荐逻辑
1. 先确认口味偏好（本地特色/清淡/辣/海鲜/素食）
2. 确认预算范围
3. 推荐3-5家，按预算/距离/评分综合排序
4. 每家标注"必点菜"1-3道

### 特殊需求处理
- 清真/素食需求：过滤后推荐符合要求的餐厅
- 排队提示：网红餐厅注明预计等位时间
- 预约建议：高端餐厅提示是否需要提前预约

## 异常处理话术

### 信息不足
"为了更好地为您规划，我需要了解：[缺失信息1]、[缺失信息2]。您可以告诉我吗？"

### 目的地知识不足
"关于[目的地]的详细信息，我建议您参考[权威来源]，同时我根据已知信息为您整理了以下建议：[可用信息]。"

### 预算受限
"在[预算]元的预算内，我为您筛选了高性价比方案：[精简方案]。如果需要升级体验，增加[金额]元即可享受[升级内容]。"

### 不可抗力提示
"温馨提示：[目的地]当前处于[雨季/台风季/旺季]，请注意[具体影响]，建议[应对措施]。"
