# 方案模板集

## 模板1: 短期游（1-2天）

适用于周末短途游、城市周边游。

```
🏞️ 【目的地】X天X夜 · 【主题】

🎯 适合人群：【人群类型】
💰 人均预算：【金额】元
📅 最佳季节：【季节】

📋 行程安排

Day 1
☀️ 上午 (9:00-12:00)
  📍 景点A - 游玩2.5h
  💰 门票：XX元
  ✨ 亮点：...

🌤️ 下午 (13:30-17:30)
  📍 景点B - 游玩3h
  💰 门票：XX元

🌙 晚上 (18:30-21:00)
  🍜 晚餐：餐厅名称（人均XX元）
  🌃 夜游：地点（如适用）

Day 2
...（同上结构）

🏨 住宿推荐
| 档次 | 名称 | 价格 | 特色 | 距景区 |
|------|------|------|------|--------|

🍜 美食清单
| 餐次 | 推荐 | 人均 | 必点 |
|------|------|------|------|

💰 费用预估
| 项目 | 费用 | 备注 |
|------|------|------|
| 交通 | XX | |
| 住宿 | XX | |
| 门票 | XX | |
| 餐饮 | XX | |
| 合计 | XX | |

💡 实用贴士
- ...
```

## 模板2: 深度游（3-5天）

适用于假期长途旅行。

```
（结构同短期游，增加以下内容）

🏛️ 每日主题
Day 1: 【主题名称】 - 抵达+市区探索
Day 2: 【主题名称】 - 核心景点
Day 3: 【主题名称】 - 深度体验
...

🗺️ 推荐路线图
[描述每日移动路线，注意不走回头路]

🚗 交通方案
| 区间 | 方式 | 耗时 | 参考费用 |
|------|------|------|----------|

🎫 门票省钱攻略
- 联票/套票推荐
- 线上预订优惠
- 淡旺季差价

⚠️ 避坑指南
- 常见套路...
- 最佳拍照时间...
- 避开人流高峰...
```

## 模板3: 主题游

根据特定主题定制（美食之旅/摄影之旅/文化之旅/亲子研学）

```
📸 【主题】之旅 · X天X夜

🎯 主题聚焦：
[描述本次旅行的核心主题和体验目标]

Day 1: 【子主题】
- 拍摄点推荐（含最佳拍摄时间/机位）
- 美食体验点
- 特色体验项目
...

📷 摄影贴士 / 🍜 美食地图 / 📚 文化笔记
[针对性专业建议]
```
